Available Commands

Yeh saare commands bot mein kaam kar rahe hain:

💬 General

  • /start - Bot ko start karein.
  • /help - Yeh help message dekhein.
  • /about - Bot ke baare mein jaanein.
  • /stats - Bot ka live performance status.
  • /id - Apni User ID aur Chat ID paayein.

🎨 Media & AI

  • /gen <prompt> - AI se image banayein.
  • /img <query> - Photo search karein.
  • /lyrics <song> - Gaane ke lyrics dhoondein.
  • /youtube <link> - YouTube video download karein.
  • /tr <lang> <text> - Text ko translate karein.

💡 Utility

  • /weather <city> - Mausam ki jaankari.
  • /crypto <symbol> - Crypto ka price dekhein.
  • /define <word> - Shabdkosh (Dictionary).
  • /ud <term> - Urban Dictionary search.
  • /qr <text> - QR code banayein.
  • /shorten <url> - URL chhota karein.
  • /paste - Text ko online paste karein (reply karke).

🎮 Fun & Games

  • /couple - Group mein random couple chunein.
  • /truth | /dare - Truth ya Dare khele.
  • /slap | /roast - User ko slap/roast karein (reply karke).
  • /rate <thing> - Kisi cheez ko rate karein.
  • /meme | /joke | /quote | /advice
  • /catfact | /dogfact
  • /roll | /coinflip
  • /startgame | /stopgame - Number guessing game.

💸 Economy & Family Game

  • /game | /profile - Apna game menu kholein.
  • /leaderboard - Sabse ameer players dekhein.
  • /marry | /divorce - Shaadi karein (reply karke).
  • /adopt - God lein (reply karke).
  • /rob | /kill - Doosre user ko lootein ya...
  • /deposit | /withdraw - Bank mein paisa daalein/nikaalein.
  • /gift - Paisa gift karein.

🔒 Admin (Group Admins)

  • /on | /off - Bot ko group mein on/off karein.
  • /reset - Chat history reset karein.
  • /ban | /kick | /mute
  • /unban | /unmute
  • /setwelcome - Custom welcome message set karein.
  • /setwelcomemedia - Custom welcome media set karein.
  • /resetwelcome - Welcome settings reset karein.

👑 Sudo (Bot Owner)

  • /poweron | /poweroff - Bot ko globally on/off karein.
  • /broadcast - Sabhi chats mein message bhejein.
  • /adminstats - Bot ka detailed report.
  • /show_chats - Bot kin groups mein hai, list dekhein.
  • /s_ban | /s_unban | /s_send
  • /addsudo | /removesudo
  • /forcedynamic | /forcegemma | /forcedeepseek
