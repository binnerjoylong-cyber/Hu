Feature & Command List

💬 General

  • /start - Initialize the bot.
  • /help - Display this help message.
  • /about - Learn about the bot.
  • /stats - Check live system stats.
  • /id - Get User & Chat ID.

🎨 Media & AI

  • /gen <prompt> - Generate AI image.
  • /img <query> - Search for a photo.
  • /lyrics <song> - Find song lyrics.
  • /youtube <link> - Download YouTube video.
  • /tr <lang> <text> - Translate text.

💡 Utility

  • /weather <city> - Get weather forecast.
  • /crypto <symbol> - Check crypto prices.
  • /define <word> - Get word definition.
  • /ud <term> - Search Urban Dictionary.
  • /qr <text> - Generate QR code.
  • /shorten <url> - Shorten a URL.
  • /paste - Paste text to a bin (reply).

🎮 Fun & Games

  • /couple - Select a random group couple.
  • /truth | /dare - Play Truth or Dare.
  • /slap | /roast - Slap or roast a user.
  • /rate <thing> - Rate anything 1-10.
  • /meme | /joke | /quote
  • /catfact | /dogfact
  • /roll | /coinflip
  • /startgame - Start guessing game.

💸 Economy & Family

  • /game | /profile - Open game menu.
  • /leaderboard - View richest players.
  • /marry | /divorce - Manage marriage.
  • /adopt - Adopt a user.
  • /rob | /kill - Risky actions.
  • /deposit | /withdraw - Use the bank.
  • /gift - Transfer money.

🔒 Admin (Group)

  • /on | /off - Toggle bot in group.
  • /reset - Clear chat history.
  • /ban | /unban
  • /kick | /mute | /unmute
  • /setwelcome - Set custom welcome.
  • /setwelcomemedia - Set welcome media.
  • /resetwelcome - Reset welcome.
